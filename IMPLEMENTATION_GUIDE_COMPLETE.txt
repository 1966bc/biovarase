```python
def main():
    import os
    import sys
    
    # Check if config.enc exists
    if not os.path.exists('config.enc'):
        # First-time setup - show wizard
        print("[INFO] config.enc not found - starting setup wizard...")
        
        # Import and show setup wizard
        try:
            import frames.setup_wizard
        except ImportError:
            print("[ERROR] frames.setup_wizard not found!")
            sys.exit(1)
        
        # Create temporary root for wizard
        import tkinter as tk
        temp_root = tk.Tk()
        temp_root.withdraw()
        
        # Show wizard
        wizard = frames.setup_wizard.SetupWizard(temp_root)
        temp_root.wait_window(wizard)
        
        # Check if setup completed
        if not wizard.success or not os.path.exists('config.enc'):
            print("[INFO] Setup canceled - exiting...")
            temp_root.destroy()
            sys.exit(0)
        
        temp_root.destroy()
        print("[INFO] Setup completed - starting application...")
    
    # Normal startup
    root = App()
    root.mainloop()
```

### 4.2 - Modifica Funzione load_credentials_from_file()

Apri `frames/login.py` e trova la funzione `load_credentials_from_file()` (circa riga 30-60).

**PRIMA (usa config.txt):**
```python
def load_credentials_from_file(file_path: str = "config.txt") -> Dict[str, str]:
    """
    Load database credentials from a text file.
    
    Args:
        file_path: Path to the credentials file.
                   Expected format: 'key=value' per line.
    
    Returns:
        Dictionary containing credentials, or empty dict on error.
    """
    credentials = {}
    
    try:
        if not os.path.exists(file_path):
            print(f"Error: Credentials file '{file_path}' not found.")
            return credentials
        
        with open(file_path, 'r') as file:
            for line in file:
                line = line.strip()
                if line and '=' in line:
                    key, value = line.split('=', 1)
                    credentials[key.strip()] = value.strip()
    
    except (FileNotFoundError, IOError) as e:
        print(f"Error reading credentials file: {e}")
    
    return credentials
```

**DOPO (usa config.enc con security):**
```python
def load_credentials_from_file(file_path: str = "config.enc") -> Dict[str, str]:
    """
    Load database credentials from encrypted configuration file.
    
    Uses hardware-locked encryption to decrypt config.enc.
    Falls back to legacy config.txt if config.enc not found.
    
    Args:
        file_path: Path to the encrypted credentials file (default: config.enc)
    
    Returns:
        Dictionary containing credentials, or empty dict on error.
    """
    # Import security module
    try:
        import security
    except ImportError:
        print("[ERROR] security.py not found!")
        print("Ensure security.py is in the project root directory.")
        return {}
    
    # Try to decrypt config.enc
    if os.path.exists(file_path):
        credentials = security.decrypt_config(file_path)
        
        if credentials:
            print(f"[INFO] Credentials loaded from {file_path}")
            return credentials
        else:
            print(f"[ERROR] Failed to decrypt {file_path}")
            print("[INFO] This may indicate:")
            print("  - Wrong machine (config.enc is hardware-locked)")
            print("  - Corrupted file")
            print("  - Re-run setup to create new config.enc")
            return {}
    
    # Fallback: Try legacy config.txt (for backward compatibility during migration)
    legacy_path = "config.txt"
    if os.path.exists(legacy_path):
        print(f"[WARNING] Using legacy {legacy_path} (plaintext - INSECURE!)")
        print("[WARNING] Consider re-running setup to create encrypted config.enc")
        
        credentials = {}
        try:
            with open(legacy_path, 'r') as file:
                for line in file:
                    line = line.strip()
                    if line and '=' in line:
                        key, value = line.split('=', 1)
                        credentials[key.strip()] = value.strip()
            return credentials
        except Exception as e:
            print(f"[ERROR] Failed to read {legacy_path}: {e}")
            return {}
    
    # Neither config.enc nor config.txt found
    print(f"[ERROR] No configuration file found!")
    print(f"Expected: {file_path} or config.txt")
    return {}
```

```markdown
# Biovarase v4.2 - Installation

## First-Time Setup

1. Extract `biovarase.dist` folder to desired location
2. Run `biovarase.exe`
3. Setup Wizard will appear (first time only)
4. Enter database credentials:
   - User: your_db_user
   - Password: your_db_password
   - Database: biovarase
   - Host: localhost (or IP)
5. Click "Test Connection" to verify
6. Click "Save" to create encrypted configuration
7. Application will start

## Security Notes

- Configuration is encrypted (AES-128 + HMAC-SHA256)
- Configuration is hardware-locked (non-transferable)
- If you reinstall on different PC, re-enter credentials
- Keep database credentials documented securely (password manager)

## Troubleshooting

**Problem:** "config.enc not found" on every startup
**Solution:** Setup wizard failed to save config.enc. Check:
  - User has write permissions in application folder
  - Antivirus not blocking file creation

**Problem:** "Failed to decrypt config.enc"
**Solution:** File was copied from different PC (hardware-locked).
  - Delete config.enc
  - Restart application
  - Re-enter credentials in Setup Wizard
```

## 🚨 TROUBLESHOOTING

### Problema: "ModuleNotFoundError: No module named 'cryptography'"

**Soluzione:**
```bash
pip install cryptography

# Se errore durante installazione su Windows:
# - Installare Visual C++ Build Tools
# - Oppure usare wheel pre-compilato:
pip install --only-binary :all: cryptography
```

### Problema: "Setup Wizard non appare al primo avvio"

**Causa:** biovarase.py non modificato correttamente

**Soluzione:**
1. Verifica modifica a biovarase.py (vedi STEP 3)
2. Verifica import frames.setup_wizard funziona:
   ```python
   python
   >>> import frames.setup_wizard
   >>> # No errore? OK!
   ```

### Problema: "config.enc created but decryption fails"

**Causa:** Hardware ID cambiato o file corrotto

**Soluzione:**
1. Elimina config.enc
2. Riavvia applicazione
3. Re-inserisci credenziali nel Setup Wizard

### Problema: "Nuitka build fails with cryptography error"

**Soluzione:**
```bash
# Assicurati che --include-package-data=cryptography sia nel build script

# Se persiste errore, prova:
pip install --upgrade nuitka
pip install --upgrade cryptography

# Ricompila:
build_biovarase.cmd
```

### Problema: "Application crashes on startup (compiled .exe)"

**Debug:**
```bash

# Verifica file inclusi:
```
